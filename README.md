# Sycun

**CISA · CAMS｜AI 安全工具与自动化测试**

做 AI 驱动的安全工具、自动化测试与代码审查。  
日常在个人仓维护 [CyberStrikeAI](https://github.com/Sycun/CyberStrikeAI)；成熟改动经独立 fork 向 [官方仓库](https://github.com/AIPentest/CyberStrikeAI) 提 PR。

常用：**Go · Python · JavaScript · MCP**

## 在做什么

| 项目 | 定位 |
| --- | --- |
| [CyberStrikeAI](https://github.com/Sycun/CyberStrikeAI) | 个人维护主线：日常修复、优化与验证 |
| [CyberStrikeAI-upstream-fork](https://github.com/Sycun/CyberStrikeAI-upstream-fork) | 官方 PR 通道：只推选定改动 |
| [csai-decouple-refactor](https://github.com/Sycun/csai-decouple-refactor) | 架构实验：分层解耦与插件化 |
| [dsh-workbench](https://github.com/Sycun/dsh-workbench) | Agent 工作台：自然语言交办与阶段汇报 |

## 上游协作

个人仓与官方 PR 通道分开：日常推个人仓；需要贡献时，从 `upstream-fork` 向 [AIPentest/CyberStrikeAI](https://github.com/AIPentest/CyberStrikeAI) 开 PR。  
另跟踪 [AIMergeBot](https://github.com/Sycun/AIMergeBot)、[ARTEX](https://github.com/Sycun/ARTEX)。
